环境与数据准备

让所有学生获得一致、可运行的 Python 3.12、Qlib 和 A 股数据环境。

◷ 15 minNotebook：第 1 节

学习目标

  • 理解 Colab 临时运行时与本地环境的区别
  • 确认 Qlib 0.9.7 与 Python 3.12 的版本约束
  • 识别数据目录和交易日历检查的作用

讲解顺序

  1. 说明为什么固定 Colab 运行时版本。

  3. 解释 464 MB 数据包解压后包含的目录。
  4. 确认最后出现“环境准备完成 ✓”。

本节检查

  • Python 显示为 3.12.x
  • 数据目录指向 /content/qlib_data/cn_data
  • calendars/day.txt 已存在
讲课提醒

首次运行时间主要消耗在依赖安装和数据下载。不要让学生在这一阶段反复重启运行时。

Module 2

初始化 Qlib

连接数据目录，设置中国市场，并建立可复现的实验记录环境。

◷ 10 minNotebook：第 2 节

学习目标

  • 理解 provider_uri、REG_CN 与股票池的关系
  • 知道 qlib.init() 为什么必须先于数据访问
  • 理解实验记录为何使用 SQLite 后端

三个关键参数

provider_uri
Qlib 二进制行情数据的位置。
region
市场规则预设，本教程使用中国市场。
exp_manager
模型参数、指标和文件的实验记录器。

本节检查

  • 初始化日志显示数据路径
  • 实验数据库为 qlib_mlflow.db
  • 股票池和基准均为沪深 300
常见错误

若看到 MLflow 文件后端处于维护模式，说明打开的仍是旧版 Notebook；新版会明确使用 SQLite。

Module 3

行情数据探索

通过 Qlib 的统一数据接口，查询成分股、原始字段和表达式特征。

◷ 30 minNotebook：第 3 节

学习目标

  • 使用 D.instruments() 获取股票池
  • 使用 D.features() 查询量价字段
  • 区分原始特征与表达式派生特征

讲解顺序

  1. 先查看沪深 300 在不同日期的成分变化。
  2. 读取开高低收、成交量等原始字段。
  3. 用 Ref、Mean 等算子构造时序特征。
  4. 完成股票筛选练习。

建议提问

  • 为什么股票池不能使用今天的成分回看历史？
  • $close 与 Ref($close, 1) 分别代表什么？
  • 缺失值可能来自哪些交易情形？
核心概念

Qlib 表达式把特征定义与数据读取合并在一起，计算发生在统一的数据接口之后。

下一节TopK 策略回测 →
6
Module 6

TopK 策略回测

把横截面预测分数转换成持仓，并在交易成本约束下模拟组合表现。

◷ 40 minNotebook：第 6 节

学习目标

  • 理解预测信号、选股策略和执行器的连接方式
  • 解释 TopK 与换仓数量参数
  • 识别手续费、滑点和涨跌停约束对结果的影响

回测链路

预测分数→TopK 选股→订单执行→账户净值

SignalRecord 生成信号，PortAnaRecord 生成组合分析结果。

本节检查

  • 回测区间只覆盖测试集
  • 基准指数与股票池口径一致
  • 交易成本已纳入报告
常见误区

预测分数不是收益率；它只负责排序。真正的组合收益还取决于持仓规则、成交限制和交易成本。

Module 7

绩效与 IC 诊断

从收益、风险、换手和预测质量四个角度判断策略是否可信。

◷ 60 minNotebook：第 7 节

学习目标

  • 解读累计收益、超额收益、最大回撤与换手率
  • 比较年化收益、波动率和信息比率
  • 使用 IC、分组收益与预测自相关诊断模型
Return策略最终赚了多少
Max Drawdown最差阶段损失多大
IC / Rank IC预测与未来收益是否一致
Turnover收益是否依赖高频换仓

建议讲解顺序

  1. 先看净值和超额收益是否稳定。
  2. 再看回撤、波动率和信息比率。
  3. 检查分组收益是否近似单调。
  4. 结合 IC 和预测自相关解释信号质量。

课后作业

  • 计算累计超额收益率。
  • 计算含成本的超额收益最大回撤。
  • 用自己的语言解释六类模型诊断图。
结束判断

一个可用策略需要同时回答：收益来自哪里、风险有多大、成本后是否仍成立、预测关系是否稳定。
